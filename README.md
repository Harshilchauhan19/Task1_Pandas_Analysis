# 📊 Student Performance Analysis using Pandas

A beginner-friendly Data Analysis project developed using **Python**, **Pandas**, **Matplotlib**, and **Seaborn**. This project loads a CSV dataset, performs basic data analysis, and visualizes the data using different charts.

---

## 📌 Project Objective

The objective of this project is to analyze student performance data by:

- Loading a CSV dataset
- Performing basic statistical analysis
- Calculating average values
- Creating data visualizations
- Drawing meaningful insights from the dataset

---

## 🚀 Features

- 📂 Load CSV Dataset using Pandas
- 📋 Display First 5 Records
- 📊 Dataset Information
- 📈 Statistical Summary
- 📉 Calculate Average Final Marks
- 📌 Find Highest & Lowest Marks
- 📊 Bar Chart
- 🔵 Scatter Plot
- 🔥 Heatmap
- 📝 Data Analysis & Insights

---
